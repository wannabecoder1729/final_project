# Emotion Detector

## Project Name
**Emotion Detector** — a Flask-based web application that uses the IBM
Watson NLP library to analyze a piece of text and detect the emotions
(anger, disgust, fear, joy, sadness) expressed in it, along with the
dominant emotion.

## Overview
This project was built as the final assignment for the "Developing AI
Applications with Python and Flask" course. It demonstrates:
- Building an emotion-detection function using Watson NLP
- Formatting the output of the application
- Packaging the application as a reusable Python package
- Running unit tests
- Deploying the application as a web service using Flask
- Handling errors (e.g., blank input)
- Running static code analysis with PyLint

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Start the server: `python3 server.py`
3. Open a browser and navigate to `http://localhost:5000`
